# /astro-lunar-calendar

Use the Astro Jyotish lunar calendar capability for today, a specified Kyiv date, or a published month. The calendar is free: no stars or subscription requests are consumed. It is a general calendar calculated for Kyiv, not a personalized chart reading.

Use the language explicitly requested by the user; otherwise use the current chat language. Dates and times use Europe/Kyiv. Return the calendar data directly in chat: lunar phase, Moon sign and nakshatra, tithi, day score, suitable activities, and relevant time changes. For a month, summarize the day rows and highlight favorable and unfavorable dates. Do not replace the data with a webpage link or HTML.

If the user's Hidden World account is not connected, use the documented connection flow. If the lunar calendar tool is not available in this plugin session, report that it is not yet available; do not invent values or calculate them locally.
