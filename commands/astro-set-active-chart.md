# /astro-set-active-chart

Select the active saved Hidden World chart for Astro Jyotish personal services.

Only select from saved charts. Do not create or calculate a new chart in this command.

If the chart is not clearly identified, ask exactly one concise question in the current chat language: which saved chart should be made active?

After selecting the chart, show the chart name if available and say that it is now active.

Do not expose chart identifiers unless the user needs them to distinguish charts with the same name. Do not expose internal endpoints, raw payloads, authentication fields, or backend implementation details.

Do not inspect or modify backend code, Lambda configuration, AWS resources, environment variables, queues, prompts, or site/service code while handling this command.
